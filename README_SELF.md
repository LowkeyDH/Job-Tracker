# 个人学习记录

这个文件用于记录我在 Job Tracker 项目中的学习计划和技能目标。

## 项目目标

- 学习如何将简历内容上传并交给 OpenAI 分析
- 实现基于简历与职位匹配的推荐系统
- 了解部署线上服务所需的流程和工具

## 计划学习的技能

1. OpenAI API 使用
   - 简历文本解析
   - 提取技能、经验和教育背景
2. 后端开发
   - 处理文件上传
   - 管理用户数据与匹配逻辑
3. 前端开发
   - 上传简历界面
   - 展示匹配结果与推荐理由
4. 部署与运维
   - 线上环境部署（如 Vercel、Netlify、Heroku 或云服务）
   - API 密钥管理与安全策略

## 学习步骤

1. 先设计简历数据流：上传 -> OpenAI 分析 -> 匹配 -> 结果输出
2. 了解 OpenAI 的请求与响应格式
3. 搭建简单样例，测试简历分析与提取能力
4. 将结果转换为职位匹配评分算法
5. 准备线上部署文档与环境配置

## 个人目标

- 在这个项目中掌握 AI 驱动的简历分析流程
- 能独立完成从上传到匹配的端到端实现
- 为未来线上服务部署打下基础
